How this works

  • upkeep keeps no database. The providers are the state; the only thing this page remembers is the last plan it ran per app, and that is gone when the server stops.
  • The config is re-read on every request, so an edit to {{.ConfigPath}} shows without a restart.
  • Credentials come from the environment or the provider's own CLI session, the same as the terminal: RENDER_API_KEY or render login, CLOUDFLARE_API_TOKEN or wrangler login, NEON_API_KEY or neonctl auth, FLY_API_TOKEN or fly auth login.
  • The password hash and the activity log live under ~/.local/share/upkeep by default ($XDG_DATA_HOME honoured), or wherever -data points.
  • Sessions live in memory: a server restart signs every browser out.
